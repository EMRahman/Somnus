# Pull request follow-up

After creating a pull request, check it every minute for up to 10 minutes from creation. Review and address any comments that arrive during that window.

If a coding agent responds to the pull request with a thumbs-up (👍), attempt to merge it only after you’ve addressed any outstanding comments and confirmed that your GitHub credentials have write access to the target repository. Stop checking when the pull request is merged or the 10-minute window ends.
